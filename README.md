# Связь поколений — Мы помним

Учебный памятный сайт о Зое Космодемьянской.

## Публикация через GitHub Pages

1. Распакуйте архив на компьютере. **Не загружайте ZIP-файл целиком** в репозиторий: загрузите сами файлы из этой папки.
2. На GitHub нажмите **New repository** и назовите его `svyaz-pokoleniy`.
3. Выберите **Public** и создайте репозиторий.
4. В репозитории нажмите **Add file → Upload files**, перетащите `index.html`, `.nojekyll` и `README.md` из распакованной папки, затем нажмите **Commit changes**.
5. Откройте **Settings → Pages**.
6. В разделе **Build and deployment** выберите **Deploy from a branch**.
7. В источнике выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
8. Вернитесь в **Settings → Pages**. Когда публикация завершится, там появится ссылка **Visit site**.

Адрес будет иметь вид `https://ВАШ-ЛОГИН.github.io/svyaz-pokoleniy/`.

## Локальный запуск и редактирование

Откройте `index.html` в браузере. Для изменения сайта редактируйте его в Visual Studio Code или другом текстовом редакторе. После изменений загрузите обновлённый `index.html` в тот же GitHub-репозиторий и сохраните коммит — GitHub Pages опубликует новую версию.

Некоторые фотографии загружаются с внешних сайтов и требуют интернет-соединения. Сообщения на стене памяти хранятся в localStorage только текущего браузера и не передаются между посетителями.
